# Original UTF-16 legacy counting maps

These four 8192-byte tables are implementation data generated by
`tools/legacy-encoding-map` from the original oracle's exact Windows x64
System.Text.Encoding.CodePages provider (10.0.9). They encode the selected-page
roundtrip, CP932 roundtrip, then selected-page fallback length decision for each
UTF-16 unit. Bit 0 means one byte and bit 1 means two bytes; ASCII uses the
explicit fast path. Surrogate units are queried separately, never combined.

`provenance.json` pins the provider, generator source hashes, all raw tuple
hashes and installed bitset hashes. Raw generation evidence is retained in the
task evidence directory, not as product runtime data. Generation is not a
behavioral acceptance claim; fixed oracle comparisons and product regressions
are recorded in the compatibility implementation log after batch completion.

The table is intentionally separate from the existing scalar encoding_rs path
used by the snake profile. Do not globally replace LegacyEncoding's old methods.
Notable .NET differences include yen best-fit widths, CP932 private-use
roundtrips, U+2212 fallback, and CP950 versus WHATWG Big5-HKSCS mappings.
