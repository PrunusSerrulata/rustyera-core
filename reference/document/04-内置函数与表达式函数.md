# 04-内置函数与表达式函数

本文讨论 **可直接写进表达式并产生返回值** 的函数，即 `TOSTR(x)`、`MAX(a,b)`、`RAND(n)`、`@自定义函数()` 这一类；**不讨论** `PRINT`、`SPLIT`、`CVARSET` 这类语句型命令。

> 结论先行：`FunctionMethodCreator` 的静态注册表里一共注册了 **345 个表达式函数**。其中既包含传统 erabasic 核心函数，也包含本仓库额外扩展的 HTML / 图形 / XML / MAP / DataTable / SQL / 音频 等函数族。本文重点详解通用核心函数，并在文末给出扩展函数总览。

## 研究依据与调用规则

- **内置函数注册总表**：`source/Emuera/MinorShift.Emuera.GameData.Function/FunctionMethodCreator.cs` 静态构造器 `methodList`。
- **表达式函数调用封装**：`FunctionMethod.cs`、`FunctionMethodTerm.cs`。
- **用户自定义表达式函数**：`UserDefinedMethodTerm.cs`、`SuperUserDefinedMethodTerm.cs`、`UserDefinedRefMethod*.cs`、`IdentifierDictionary.GetFunctionMethod(...)`。
- **参数检查**：`FunctionMethod.CheckArgumentType` / `CheckArgumentTypeEx`，以及 `ArgumentParser` / `ArgumentBuilder`。

### 通用规则

1. **名字解析顺序**  
   表达式里的 `NAME(...)` 会优先尝试：
   - 用户自定义函数引用（`UserDefinedRefMethod`）
   - `#FUNCTION/#FUNCTIONS/#FUNCTIONF` 声明的用户函数
   - 内置函数注册表  
   见：`IdentifierDictionary.GetFunctionMethod(...)`。

2. **可选参数 / 省略参数**  
   多数函数通过 `ArgTypeList.OmitStart` 实现可选尾参数；文中参数表里的 `[]` 就是这个意思。

3. **浮点返回提升**  
   `MAX/MIN/RAND/ABS/POWER/SQRT/...` 这类函数在源码里 `CanReturnFloat = true`。  
   如果实参里出现浮点表达式，整个函数表达式会被提升为 **浮点返回**；否则按整数返回。见：`FunctionMethodTerm.ResolveEraType(...)`。

4. **并非所有表达式函数都是“纯函数”**  
   例如 `BITSET`、`SETVAR`、`SQL_EXECUTE_NONQUERY`、`HOTKEY_STATE` 都会修改状态，只是它们依然以“函数形式”返回一个值。

## 8. 用户自定义函数机制

## 8.1 声明方式

源码明确支持三种表达式函数声明：

- `#FUNCTION`：**整数返回**
- `#FUNCTIONS`：**字符串返回**
- `#FUNCTIONF`：**浮点返回**（源码支持，但本仓库 `ERB/` 未检出实际例子）

相关解析点：
- `LogicalLineParser` 会把 `#FUNCTION / #FUNCTIONS / #FUNCTIONF` 记到 `FunctionLabelLine.MethodType`
- `IdentifierDictionary.GetFunctionMethod(...)` 会在表达式中把 `@函数名(...)` 解析成 `UserDefinedMethodTerm` 或 `UserDefinedRefMethodTerm`
- `RETURNF` 最终通过 `state.ReturnF(ret)` 把返回值交给调用方，而不是靠 `RESULT/RESULTS`

### 实际例子

```erb
@SPIRIT_颜像索引(ARGS)
#FUNCTIONS
RETURNF @"颜%ARGS%"
```

来源：`ERB/魔改内容/GRAPH系.ERB:203-206`

## 8.2 参数声明语法（按源码）

`UserDefinedFunctionData.Create(...)` 支持的形态是：

```erb
#FUNCTION  FUNCNAME(INT, STR)
#FUNCTIONS FUNCNAME(REF INT: , STR)
#FUNCTIONF FUNCNAME(OUT STR:, FLOAT)
```

可用关键字：

- `INT` / `STR` / `FLOAT`
- `REF`：引用参数
- `OUT`：输出引用参数（源码中会打上 `__Out` 标记）
- `:`：每多一个 `:` 就多一维数组引用  
  例如 `REF INT:` = `REF INT 1维数组`，`REF STR::` = `REF STR 2维数组`

> `UserDefinedFunctionData` 明确限制：引用数组维度不能超过 3（也就是 `REF xxx:::`, 含角色维之外的常规 3 维）。

## 8.3 值传递 / 引用传递

- 普通参数：调用时会先 `Restructure`，按值求值后传入。
- `REF/OUT` 参数：`UserDefinedRefMethodTerm.Restructure(...)` 不会把它替换成常量，而是保留可写引用。
- 引用签名必须 **返回类型一致 + 参数个数一致 + 每个参数的值/引用/维度/类型一致**，由 `UserDefinedRefMethod.MatchType(...)` 检查。

## 8.4 返回值机制

- `RETURNF expr`：返回表达式值。
- 如果函数体没有形成有效返回值，`SuperUserDefinedMethodTerm.GetValue(...)` 会给默认值：
  - 整数函数：`0`
  - 浮点函数：`0.0`
  - 字符串函数：`""`

### 重要区分：`RETURNF` 与 `RESULT/RESULTS`

- **用户自定义表达式函数的真正返回通道是 `RETURNF`**。
- `RESULT` / `RESULTS` 不是“函数返回寄存器”；它们只是普通系统变量，某些内置函数（如 `REGEXPMATCH`、`CHKDATA`、`XML_GET`、`ENUM*`）会顺带写它们。

## 8.5 动态调用用户函数

除了直接写 `@FUNC(...)`，源码还注册了：

- `GETMETH` / `GETMETHS` / `GETMETHF`：按名字动态调用用户表达式函数
- `EXISTMETH`：只检查用户表达式函数是否存在
- `ARGLEN`：读取当前可变参数长度

这几组函数本质上也是用户自定义函数机制的一部分。
