# 00 总览：eratw-sub-modding ERA/Emuera 语法文档

本系列文档面向 `eratw-sub-modding` 仓库，系统整理 **erabasic 脚本语言**（`.ERB`/`.ERH` 文件）与
**CSV 数据格式**的语法规范。所有结论均以 `source/Emuera`（本仓库自带、经过修改的 Emuera 引擎 C# 源码，
.NET 8）为第一权威依据，并结合 `CSV/` 与 `ERB/` 目录中的真实脚本/数据文件进行交叉验证。

> 本仓库是 Emuera 官方引擎的一个 **fork / 修改版**（用于 eraTW 系列文字游戏及其汉化/魔改），
> 因此部分行为（例如是否支持某个宏、某个函数、某个 PRINT 后缀）**可能与网络上流传的“标准 Emuera 文档”不完全一致**。
> 本系列文档以本仓库的 `source/Emuera` 实际代码为准，遇到分歧会在正文中明确指出并标注来源；
> 无法在源码中确认的内容，一律标注为“需进一步验证”，不做臆测。

## 文档编写方法说明

1. **权威来源优先级**：`source/Emuera` 源码 > `CSV/`/`ERB/` 实际文件内容 > 通用 Emuera 知识。
2. **交叉验证**：每个语法点尽量在 `ERB/` 目录中找到真实脚本引用作为示例；找不到用例的语句会在对应文档中单独列出，提示"源码中存在但仓库未见实际用法"。
3. **不臆造**：源码未直接证实、且无法从文件内容合理推断的行为，一律标注"需进一步验证"，不作为确定结论呈现。
4. **术语统一**：
   - "语句/命令"指以整行形式出现、不返回值嵌入表达式的指令（如 `PRINTFORM`、`CALL`），归入 02/03 文档；
   - "函数"指可以写在表达式内部、有返回值的调用（如 `TOSTR()`），归入 04 文档；
   - "变量"指 `VariableCode.cs` 中注册的内置标识符（如 `TALENT`、`FLAG`），归入 05 文档。

## 已知的与"传闻中的标准 Emuera"不同之处（详见各文档正文）

- 未在词法分析器中发现 `//` 注释语法，标准注释符为 `;`。
- 三元表达式写法为 `条件 ? 值1 # 值2`（`#` 而非 `:`），详见 01 文档。
- 若干在网络教程中常见的函数/宏，在本仓库源码中未找到对应实现，已在 04/06 文档末尾列出"未确认存在"清单。
