# 03-内置命令大全

本文只讨论 **语句型内置命令**；`IF/FOR/WHILE/CALL/GOTO/TRY/RETURN/FUNC/BEGIN/RESTART/QUIT/THROW/ASSERT` 等控制流命令已由另一份文档负责，`TOSTR/MAX/RAND/POWER(...)` 这类**表达式函数**见《04-内置函数与表达式函数》。本文源码基线为 `source/Emuera`（.NET 8 分支）。

> 说明
>
> - 文中的“语法”写成 **ERB 常用写法**；少数命令（如 `SET`）在引擎内部有 `FunctionCode`，但脚本实际写法是赋值语句而不是 `SET ...`。
> - `RESULT / RESULTS / RESULT_ARRAY` 等返回槽遵循 Emuera 传统约定。
> - **凡源码尚未实现或语义仍不完全明确者，均标注“需进一步验证”**。

## 输出命令/PRINT系列

### PRINT 家族总规则（先读这一节）

- `PRINT_Instruction(string name)` 会按固定顺序解析后缀：`SINGLE -> V/S/FORMS/FORM/默认 -> LC/C -> K -> D -> N -> L/W`。
- 基础参数形态：
  - 默认 `PRINT`：读取**原始字符串字面量**。
  - `PRINTS`：读取**字符串表达式**。
  - `PRINTFORM`：对字符串参数做格式化插值解析。
  - `PRINTFORMS`：先求值字符串表达式，再做格式化解析。
  - `PRINTV`：把多个表达式按 `SpPrintVArgument` 逐段拼接。
- 其他后缀：
  - `C` / `LC`：按 `PrintC` 多列排版（右对齐 / 左对齐）。
  - `K`：输出前执行假名/宽度转换（`ConvertStringType(...)`）。
  - `D`：本次输出不继承 `SETCOLOR` 样式。
  - `N`：不自动换行。
  - `L`：输出后换行。
  - `W`：输出后换行并等待按键。
  - `SINGLE*`：走 `Console.PrintSingleLine(...)`，绕过常规 print buffer 的换行/等待路径。

```erb
PRINT "普通字面量"
PRINTS STR:0
PRINTFORM "当前金钱：{MONEY}"
PRINTFORMS HTMLWRAP("{CALLNAME:TARGET}")
PRINTV "HP=", BASE:0, "/", MAXBASE:0
PRINTW "这一行输出后会等待"
```

- 来源：`source/Emuera/MinorShift.Emuera.GameProc.Function/FunctionIdentifier.cs:74-151,4316-4415`，`source/Emuera/MinorShift.Emuera.Runtime.Script.Statements/ExpressionMediator.cs:44-66`，`source/Emuera/MinorShift.Emuera.GameView/EmueraConsole.cs:3491-3655`。

### PRINT / PRINTL / PRINTW / PRINTN

- 语法：
  - `PRINT "文本"`
  - `PRINTL "文本"`
  - `PRINTW "文本"`
  - `PRINTN "文本"`
- 功能：默认字面量输出；`L` 换行，`W` 换行并等待，`N` 不换行。
- 示例：

```erb
PRINT "第一段"
PRINTN " ← 紧跟上一段"
PRINTL "，这里结束当前行"
PRINTW "按键后继续"
```

- 来源：`FunctionIdentifier.cs:74-151,4316-4390`，`ExpressionMediator.cs:44-66`。

### PRINTV / PRINTVL / PRINTVW / PRINTVN

- 语法：`PRINTV expr1, expr2, ...`
- 功能：把多个表达式直接拼成一条输出文本；后缀 `L/W/N` 规则与 `PRINT` 相同。
- 示例：

```erb
PRINTVL "HP=", BASE:TARGET:0, "/", MAXBASE:TARGET:0
PRINTVW "金钱=", MONEY
```

- 来源：`FunctionIdentifier.cs:91-104,4316-4390`，`source/Emuera/MinorShift.Emuera.Runtime.Script.Statements/SpPrintVArgument.cs`。

### PRINTS / PRINTSL / PRINTSW / PRINTSN

- 语法：`PRINTS strExpr`
- 功能：把参数当作**字符串表达式**求值后输出；适合变量、函数返回值。
- 示例：

```erb
LOCALS = "来自变量的文本"
PRINTSL LOCALS
```

- 来源：`FunctionIdentifier.cs:96-108`。

### PRINTFORM / PRINTFORML / PRINTFORMW / PRINTFORMN

- 语法：`PRINTFORM "格式串"`
- 功能：对字符串做格式化插值后再输出。
- 示例：

```erb
PRINTFORML "当前对象：{CALLNAME:TARGET}"
PRINTFORMW "金钱：{MONEY}"
```

- 来源：`FunctionIdentifier.cs:107-118`。

### PRINTFORMS / PRINTFORMSL / PRINTFORMSW / PRINTFORMSN

- 语法：`PRINTFORMS strExpr`
- 功能：先把参数作为字符串表达式求值，再执行格式串解析；适合“动态生成格式串”。
- 示例：

```erb
LOCALS = "现在时间：{DAY}:{TIME}"
PRINTFORMSL LOCALS
```

- 来源：`FunctionIdentifier.cs:107-118`。

### PRINTC / PRINTLC / PRINTFORMC / PRINTFORMLC

- 语法：
  - `PRINTC "文本"`
  - `PRINTLC "文本"`
  - `PRINTFORMC "格式串"`
  - `PRINTFORMLC "格式串"`
- 功能：调用 `Console.PrintC(...)` 进行“固定列宽”排版；`C` 为右对齐，`LC` 为左对齐。
- 示例：

```erb
PRINTLC "名称"
PRINTC MONEY
PRINTFORMLC "{CALLNAME:TARGET}"
```

- 来源：`FunctionIdentifier.cs:120-138`，`EmueraConsole.cs:3609-3655`。

### PRINTK / PRINTD 后缀族

- 语法：任一 PRINT 变体都可继续追加 `K` 或 `D`，如：
  - `PRINTKL "..."`
  - `PRINTFORMDW "..."`
  - `PRINTSINGLEFORMSK expr`
- 功能：
  - `K`：输出前做假名/宽度转换。
  - `D`：本次输出不继承 `SETCOLOR` 样式。
- 示例：

```erb
PRINTKL "ｶﾀｶﾅ/かな 统一处理"
PRINTFORMDW "这行不吃 SETCOLOR，且输出后等待"
```

- 来源：`FunctionIdentifier.cs:139-151,4316-4390`，`ExpressionMediator.cs:58-66`。

### PRINTSINGLE / PRINTSINGLEV / PRINTSINGLES / PRINTSINGLEFORM / PRINTSINGLEFORMS（含 K/D 派生）

- 语法：
  - `PRINTSINGLE "文本"`
  - `PRINTSINGLEV expr1, expr2, ...`
  - `PRINTSINGLES strExpr`
  - `PRINTSINGLEFORM "格式串"`
  - `PRINTSINGLEFORMS strExpr`
- 功能：单行立即输出，走 `Console.PrintSingleLine(...)`；不会再套用普通 `PRINT` 的缓冲换行/等待逻辑。
- 示例：

```erb
PRINTSINGLE "即时覆盖/即时提示用单行"
PRINTSINGLEV "状态：", RESULT
```

- 来源：`FunctionIdentifier.cs:74-151,4316-4390`，`ExpressionMediator.cs:44-55`。

### PRINTDATA / PRINTDATAL / PRINTDATAW（以及 K/D 派生）

- 示例：

```erb

    DATA "第一条"

```

- 来源：`FunctionIdentifier.cs:232-316,4391-4427`。

## 输入命令

### WAIT / WAITANYKEY / FORCEWAIT

- 语法：
  - `WAIT`
  - `WAITANYKEY`
  - `FORCEWAIT`
- 功能：
  - `WAIT`：普通等待按键。
  - `WAITANYKEY`：允许任意键结束等待。
  - `FORCEWAIT`：`anykey=false, stopMesskip=true`，会强制中断消息跳过。
- 示例：

```erb
PRINTL "请阅读这段提示"
WAITANYKEY
FORCEWAIT
```

- 来源：`FunctionIdentifier.cs:838-874,4438-4445`。

### TWAIT

- 语法：`TWAIT timeMs, voidMode`
- 功能：先 `ReadAnyKey()`，随后进入限时等待；第二参数非 0 时改为 `InputType.Void`。
- 示例：

```erb
TWAIT 3000, 0
```

- 来源：`FunctionIdentifier.cs:876-900`。

### INPUT / INPUTS

- 语法：
  - `INPUT [defaultInt[, mouse[, canskip]]]`
  - `INPUTS [defaultStr[, mouse[, canskip]]]`
- 功能：整数 / 字符串输入；结果写入 `RESULT` 或 `RESULTS`。`mouse` 非 0 时允许鼠标输入；`canskip` 非空且当前 MesSkip 开启时，直接返回默认值。
- 示例：

```erb
INPUT 0
PRINTFORML "你输入了整数：{RESULT}"
INPUTS "默认名称"
PRINTFORML "你输入了字符串：{RESULTS}"
```

- 来源：`FunctionIdentifier.cs:903-989`，`ArgumentParser.cs:1219-1262,2516-2554`，`source/Emuera/MinorShift.Emuera.Runtime.Script.Statements/InputRequest.cs:1-30`。

### ONEINPUT / ONEINPUTS

- 语法：
  - `ONEINPUT [defaultInt[, mouse[, canskip]]]`
  - `ONEINPUTS [defaultStr[, mouse[, canskip]]]`
- 功能：与 `INPUT/INPUTS` 相同，但 `OneInput=true`，普通键盘路径只接受 1 个字符。
- 示例：

```erb
ONEINPUTS "Y"
SIF RESULTS == "Y"
    PRINTL "确认"
```

- 来源：`FunctionIdentifier.cs:991-1033`，`EmueraConsole.cs:1649-1652`。

### TINPUT / TINPUTS

- 语法：
  - `TINPUT timeMs, defaultInt[, displayTime[, timeoutMes[, mouse[, canskip]]]]`
  - `TINPUTS timeMs, defaultStr[, displayTime[, timeoutMes[, mouse[, canskip]]]]`
- 功能：限时输入；`displayTime` 控制是否显示倒计时，`timeoutMes` 为超时提示文本。
- 示例：

```erb
TINPUT 5000, 0, 1, "超时，默认返回 0"
TINPUTS 5000, "NO", 1, "超时"
```

- 来源：`FunctionIdentifier.cs:1079-1190`，`ArgumentParser.cs:1530-1586`。

### TINPUTNF / TINPUTSNF

## 画面绘制

### DRAWLINE / DRAWLINEFORM / CUSTOMDRAWLINE

## 颜色字体

### SETCOLOR / SETCOLORBYNAME / RESETCOLOR

- 语法：
  - `SETCOLOR rgb`
  - `SETCOLOR r, g, b`
  - `SETCOLORBYNAME "Red"`
  - `RESETCOLOR`
- 功能：设置前景色；`SETCOLOR` 可传单个 `0xRRGGBB` 或三个 `0..255` 分量；`SETCOLORBYNAME` 使用 .NET `Color.FromName`；`RESETCOLOR` 恢复为 `Config.ForeColor`。
- 备注：颜色名若为 `transparent` 或无效名称会报错。
- 示例：

```erb
SETCOLOR 0xFF5555
PRINTL "红字"
SETCOLOR 255, 255, 0
SETCOLORBYNAME "Aqua"
RESETCOLOR
```

- 来源：`Process.cs:1556-1643`，`FunctionIdentifier.cs:4496-4500,1616-1628`，`ArgumentParser.cs:1990-2053`。

### FONTBOLD / FONTITALIC / FONTREGULAR / FONTSTYLE / SETFONT

- 语法：
  - `FONTBOLD`
  - `FONTITALIC`
  - `FONTREGULAR`
  - `FONTSTYLE styleBits`
  - `SETFONT "字体名"`
- 功能：
  - `FONTBOLD` / `FONTITALIC`：在当前样式上叠加粗体/斜体。
  - `FONTREGULAR`：直接重置为 `Regular`。
  - `FONTSTYLE`：位标志组合：`1=Bold, 2=Italic, 4=Strikeout, 8=Underline`。
  - `SETFONT`：切换字体族。
- 示例：

