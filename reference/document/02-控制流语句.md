## 1. 总览：命名规律与阅读方式

## 1.1 大小写
所有关键字是否区分大小写，依旧由 `Config.IgnoreCase` 控制；脚本中通常按“不区分大小写”使用。

源码：`Config.cs`、`FunctionIdentifier.cs`。

## 1.2 常见命名规律

| 形式 | 含义 |
|---|---|
| `XXXFORM` | 该语句有一段参数按 **FORM 字符串** 解析；对 `CALLFORM/GOTOFORM/JUMPFORM` 系列来说，是“目标名支持拼接/插值” |
| `TRYXXX` | 失败时**静默失败**，不抛错，不进入 `CATCH` |
| `TRYCXXX` | 失败时跳到同块的 `CATCH ... ENDCATCH` |
| `XXXSTR` | 把一整段字符串在运行期重新解析为“函数名 + 参数” |
| `XXXF` | 针对 `#FUNCTION/#FUNCTIONS/#FUNCTIONF` 用户函数（方法） |

源码：`FunctionCode.cs`、`FunctionIdentifier.cs`、`ArgumentParser.cs`。

## 2. 条件语句：`IF` / `SIF`

## 2.1 `IF` / `ELSEIF` / `ELSE` / `ENDIF`

### 语法
```erb
IF 条件
    ...
ELSEIF 条件
    ...
ELSE
    ...
ENDIF
```

### 执行语义
- `IF` 会遍历自身记录的 `IfCaseList`；
- 依次检查 `IF` / `ELSEIF` 条件；
- 第一个非 0 条件分支被执行；
- 若都不成立且存在 `ELSE`，则跳到 `ELSE`；
- 若都不成立且没有 `ELSE`，则直接跳到 `ENDIF` 后。

`ELSE` / `ELSEIF` 自己被执行到时会直接跳过整个结构末尾；真正的分支选择是 `IF_Instruction` 在入口统一完成的。

### 参数
- 条件必须能求成整数；非 0 为真，0 为假。
- `ELSE` 无参数。

### 真实示例
```erb
IF 服装 == ""
    IF CHECK_NUDE(TARGET_CHARA)
        服装 = 裸
    ELSE
        服装 = 服
    ENDIF
    CALL IMAGE_CHARA_OVERRIDE("特殊服装", VIS_C,,, TARGET_CHARA)
    IF RESULT:1
        服装 += RESULTS
    ENDIF
ENDIF
```

示例出处：`ERB/魔改内容/GRAPH系.ERB:32-43`

### 源码
- 解析/配对：`ErbLoader.cs`
- 执行：`FunctionIdentifier.cs`（`IF_Instruction`、`ELSEIF_Instruction`、`ENDIF_Instruction`）
- 枚举：`FunctionCode.cs`

## 2.2 `SIF`

### 语法
```erb
SIF 条件
    下一条语句
```

### 执行语义
- `SIF` 只作用于**紧随其后的那一条逻辑行**；
- 条件为 0 时，执行器调用 `state.ShiftNextLine()` 再跳过下一行；
- 条件非 0 时，下一行照常执行。

### 限制
- `SIF` 后不能跟“部分控制语句”之类不允许的目标；
- `SIF` 与下一条语句之间若隔了空白行，会给出兼容性警告。

### 真实示例
```erb
SIF TARGET_CHARA == -1
    TARGET_CHARA = VIS_C
```

示例出处：`ERB/魔改内容/GRAPH系.ERB:20-21`

### 源码
- 解析跳转：`FunctionIdentifier.cs`（`SIF_Instruction.SetJumpTo`）
- 执行：`FunctionIdentifier.cs`（`SIF_Instruction.DoInstruction`）

## 3. 循环语句：`FOR` / `REPEAT` / `WHILE` / `DO`

## 3.1 `FOR` / `NEXT`

### 语法
```erb
FOR 计数变量, 起始值, 终止值[, 步长]
    ...
NEXT
```

源码还允许把起始值/步长留空：
- 省略起始值 -> `0`
- 省略步长 -> `1`

### 执行语义
入口执行时：
1. 计数变量设为 `起始值`；
2. 保存 `终止值` 与 `步长`；
3. 若第一次就不满足循环条件，则直接跳到 `NEXT` 之后。

回到 `NEXT` 时：
1. 计数变量加上步长；
2. 若 `step > 0`，则要求 `end > current` 才继续；
3. 若 `step < 0`，则要求 `end < current` 才继续。

因此这是**半开区间式语义**：
- `FOR I, 0, 3` 实际执行 `I = 0, 1, 2`；
- `FOR I, 1, 167` 实际执行 `1..166`。

### 真实示例
```erb
FOR LOCAL, 0, VARSIZE("特效")
    ...
NEXT
```

示例出处：`ERB/魔改内容/GRAPH系.ERB:503-514`

### 源码
- 参数：`ArgumentParser.cs`（`SP_FOR_NEXT_ArgumentBuilder`）、`SpForNextArgment.cs`
- 执行：`FunctionIdentifier.cs`（`REPEAT_Instruction` / `REND_Instruction`，`FOR/NEXT` 共用）
- 配对：`ErbLoader.cs`

## 3.2 `REPEAT` / `REND`

### 语法
```erb
REPEAT 次数
    ...
REND
```

### 执行语义
源码把 `REPEAT n` 直接转换成：
- 循环变量：系统变量 `COUNT`
- 起始值：`0`
- 终止值：`n`
- 步长：`1`

所以：
- `COUNT` 从 `0` 开始；
- 总共执行 `n` 次；
- 每轮 `COUNT` 依次为 `0..n-1`。

### 真实示例
```erb
REPEAT 100
    PRINTL
REND
```

示例出处：`ERB/魔改内容/SUPPORT.ERB:44-46`

### 源码
- 参数重写：`ArgumentParser.cs`（`FunctionCode.REPEAT` 特判）
- 执行：`FunctionIdentifier.cs`（`REPEAT_Instruction`、`REND_Instruction`）

## 3.3 `WHILE` / `WEND`

### 语法
```erb
WHILE 条件
    ...
WEND
```

### 执行语义
- `WHILE` 入口先求值；为 0 则直接跳到 `WEND` 后；
- 到 `WEND` 时再次检查 `WHILE` 的原始条件；非 0 则跳回 `WHILE`。

### 真实示例
```erb
CURRENT_RAND_VALUE = RAND:ARG
WHILE CURRENT_RAND_VALUE == LAST_RAND_VALUE
    CURRENT_RAND_VALUE = RAND:ARG
WEND
```

示例出处：`ERB/魔改内容/SUPPORT.ERB:44-49`

### 源码
- 执行：`FunctionIdentifier.cs`（`WHILE_Instruction`、`WEND_Instruction`）
- 配对：`ErbLoader.cs`

## 3.4 `DO` / `LOOP`

### 语法（按本 fork 实现）
```erb
DO
    ...
LOOP 条件
```

### 关键校正
源码中**没有** `UNTIL` 关键字实现，也没有 `LOOP WHILE ...` / `LOOP UNTIL ...` 词法分支；
当前实现就是：
- `DO` 无参数；
- `LOOP` 接一个整数表达式；
- 表达式非 0 时继续循环。

### 执行语义
- `DO` 本身只负责建立块结构；
- `LOOP` 求值非 0 时跳回 `DO`；为 0 时结束。

### 真实示例
```erb
DO
    CLEARLINE LINECOUNT - OHEYA_LOOP_LINE
    INPUT
    IF GROUPMATCH(RESULT, 0, CFLAG:MASTER:現在位置) || RESULT < 0
        RETURN 2
    ENDIF
    IF RESULT >= MINROOM(LOCAL_MAP) && RESULT <= MAXROOM(LOCAL_MAP)
        NUM_RES = RESULT
        GOTO PROCESS_MOVE_LOGIC
    ENDIF
LOOP 1
```

示例出处：`ERB/魔改内容/qol/qol_MAP.ERB:269-279`

### 源码
- 执行：`FunctionIdentifier.cs`（`LOOP_Instruction`）
- 配对：`ErbLoader.cs`

## 4. 分支语句：`SELECTCASE`

### 语法
```erb
SELECTCASE 表达式
    CASE 值1
    CASE IS >= 10
    CASE 1 TO 5
    CASE 1, 3, 5
    CASEELSE
ENDSELECT
```

### `CASE` 支持的匹配模式
源码 `ExpressionParser.reduceCaseExpression` 明确支持 3 类：
1. **普通单值**：`CASE 9`
2. **`IS` 比较**：`CASE IS >= 10`
3. **`TO` 范围**：`CASE 1 TO 5`

此外 `CASE` 行可用逗号写多个表达式：
```erb
CASE 1, 3, 5
CASE IS < 0, IS > 100
CASE 1 TO 5, 10 TO 20
```

### 执行语义
- `SELECTCASE` 先求选择表达式；
- 若所有 `CASE` 都是**常量普通值**，加载阶段会尝试构建 `SelectCaseJumpTable` 做快速跳表；
- 否则运行时按顺序逐个判断；
- 首个匹配 `CASE` 被执行；
- 全不匹配时执行 `CASEELSE`；
- 若也没有 `CASEELSE`，直接落到 `ENDSELECT` 后。

### 真实示例
```erb
SELECTCASE TFLAG:50
    CASE 9
        L_PARTNER = MASTER_POSE(SET_M, SET_P, 1)
    CASE 11
        L_PARTNER = MASTER_POSE(SET_B, SET_P, 1)
    CASE 99
        SELECTCASE ADD_SELECTED_SCOM
            CASE 12
                L_PARTNER = ADD_MASTER_POSE_TR(PLAYER, SET_YUBI,SET_P, 1)
            CASE 21
                L_PARTNER = ADD_MASTER_POSE_TR(PLAYER, SET_LEG,SET_P, 1)
            CASEELSE
        ENDSELECT
    CASEELSE
ENDSELECT
```

示例出处：`ERB/魔改内容/GRAPH系.ERB:638-654`

### 源码
- 配对/类型检查：`ErbLoader.cs`
- `CASE` 语法：`ArgumentParser.cs`、`ExpressionParser.cs`、`CaseArgument.cs`、`CaseExpression.cs`
- 快速跳表：`SelectCaseJumpTable.cs`
- 执行：`FunctionIdentifier.cs`（`SELECTCASE_Instruction`）

## 5. 循环控制：`BREAK` / `CONTINUE`

## 5.1 `BREAK`

### 语法
```erb
BREAK
```

### 执行语义
- 跳出最近一层 `REPEAT/FOR/WHILE/DO`；
- 若跳出的是 `FOR/REPEAT`，源码会先把循环计数变量再改动一次（`+= step`），然后跳到匹配结束语句之后；
- 写在非循环体内会在加载阶段报错。

### 真实示例
```erb
TRYCCALLFORM SPIRIT_Version{count}
    IF RESULTS == "AS06MARKIV"
        H = 1
        BREAK
    ENDIF
CATCH
ENDCATCH
```

示例出处：`ERB/魔改内容/GRAPH系.ERB:603-610`

### 源码
- 配对：`ErbLoader.cs`
- 执行：`FunctionIdentifier.cs`（`BREAK_Instruction`）

## 5.2 `CONTINUE`

### 语法
```erb
CONTINUE
```

### 执行语义
- 继续最近一层循环的下一轮；
- `FOR/REPEAT`：先 `+= step`，再决定是否继续；
- `WHILE`：重新检查 `WHILE` 条件；
- `DO`：重新检查配对 `LOOP` 的条件。

### 真实示例
```erb
FOR count, 1, 167
    SIF !EXISTFUNCTION(@"SPIRIT_Version{count}")
        CONTINUE
    ...
NEXT
```

示例出处：`ERB/魔改内容/GRAPH系.ERB:597-600`

### 源码
- 配对：`ErbLoader.cs`
- 执行：`FunctionIdentifier.cs`（`CONTINUE_Instruction`）

## 6. 局部跳转：`GOTO` / `GOTOFORM`

### 语法
```erb
GOTO 标签名
GOTOFORM FORM形式的标签名
```

### 执行语义
- 目标必须是当前函数中的 `$标签`；
- 常量目标在加载阶段直接解析为 `GotoLabelLine`；
- `FORM` 版本把目标名先按 FORM 字符串求值再查找；
- `TRYGOTO` / `TRYGOTOFORM` 找不到目标时静默失败；
- `TRYCGOTO` / `TRYCGOTOFORM` 找不到目标时跳入 `CATCH` 块。

### 真实示例
```erb
SETCOLOR C_PINK
GOTO WEATHER_INFO
...
$WEATHER_INFO
PRINTFORM ― %GET_WEATHER(ARG:2)% ―
...
GOTO SKIP
```

示例出处：`ERB/魔改内容/qol/qol_weather.ERB:387-404`

### 源码
- 标签定义：`LogicalLineParser.cs`、`GotoLabelLine.cs`
- 执行：`FunctionIdentifier.cs`（`GOTO_Instruction`）
- 标签解析：`CalledFunction.cs`

> 本仓库 `ERB/` 中未检索到 `GOTOFORM` 的现成用例，但源码已实现。

## 7. 函数调用与尾调用：`CALL` / `JUMP` 系列

## 7.1 `CALL` / `CALLFORM`

### 语法
```erb
CALL 函数名[(参数...)]
CALLFORM FORM形式函数名[(参数...)]
```

还允许在函数名后写 `[...]` 子名列表；源码参数结构体中对应 `SubNames`。

### 执行语义
- 目标是**普通 `@函数`**，不能是事件，也不能是 `#FUNCTION*` 用户函数；
- `CALLFORM` 的区别仅在于“目标函数名本身可由 FORM 字符串生成”；
- 参数在进入函数前做类型与默认值转换；
- 成功后压栈进入被调函数；返回后继续当前函数下一行。

### 真实示例
```erb
CALL SPIRIT_BUILD_特效差分(,VIS_C,CFLAG:VIS_C:差し替え適用)
CALL IMAGE_CHARA_OVERRIDE("特殊服装", VIS_C,,, TARGET_CHARA)
```

示例出处：`ERB/魔改内容/GRAPH系.ERB:25,38`

## 7.2 `JUMP` / `JUMPFORM`

### 语法
```erb
JUMP 函数名[(参数...)]
JUMPFORM FORM形式函数名[(参数...)]
```

### 执行语义
`JUMP` 与 `CALL` 最大差别是：**它是尾调用式跳转**。
- 实现上仍然进入目标函数；
- 但 `CalledFunction.IsJump = true`；
- 在 `ProcessState.Return` 中，返回时会先把当前调用帧弹掉，再继续向上返回；
- 因而不会回到发起 `JUMP` 的函数体继续执行。

### 真实示例
```erb
JUMP QOL_ITEMDATA(ARG, ARGS, ARG:1)
```

示例出处：`ERB/SHOP関連/ITEMDATA.ERB:17`

### 源码
- 参数：`ArgumentParser.cs`（`SP_CALL_ArgumentBuilder`）
- 执行：`FunctionIdentifier.cs`（`CALL_Instruction`）
- 栈行为：`ProcessState.cs`

## 9. 字符串驱动调用：`CALLSTR` / `JUMPSTR` / `TRY*STR`

### 语法
```erb
CALLSTR 字符串表达式
JUMPSTR 字符串表达式
TRYCALLSTR 字符串表达式
TRYJUMPSTR 字符串表达式
TRYCJUMPSTR 字符串表达式
TRYCCALLSTR 字符串表达式
```

字符串内容会在运行期被重新解析成：
- 函数名
- 可选 `(...)` 参数列表

### 执行语义
- `CALLSTR` / `JUMPSTR` 分别等价于动态版 `CALL` / `JUMP`；
- `TRY*STR` 与 `TRYC*STR` 的失败规则和普通 `TRY*` / `TRYC*` 一致；
- 解析字符串本身失败时，`TRY*STR` 会吞掉异常，`TRYC*STR` 会进入 `CATCH`。

### 真实示例
```erb
TRYCCALLSTR RESULTS
    PRINTW 函数正常调用结束
CATCH
    PRINTW 函数调用失败
ENDCATCH
```

示例出处：`ERB/SHOP関連/TEST.ERB:13-18`

### 源码
- 执行：`FunctionIdentifier.cs`（`CALLS_Instruction`）
- 词法重解析：`LexicalAnalyzer.cs`、`ExpressionParser.cs`

## 11. `TRY*` 与 `TRYC*`、`CATCH` / `ENDCATCH`

## 11.1 普通 `TRY*`
包括：
- `TRYCALL` / `TRYCALLFORM`
- `TRYJUMP` / `TRYJUMPFORM`
- `TRYGOTO` / `TRYGOTOFORM`
- `TRYCALLF` / `TRYCALLFORMF`
- `TRYCALLSTR` / `TRYJUMPSTR`

### 语义
- 目标不存在、参数不匹配、动态解析失败时：**不报错，直接跳过**。

## 11.2 `TRYC*` + `CATCH` / `ENDCATCH`
包括：
- `TRYCCALL` / `TRYCCALLFORM`
- `TRYCJUMP` / `TRYCJUMPFORM`
- `TRYCGOTO` / `TRYCGOTOFORM`
- `TRYCCALLSTR` / `TRYCJUMPSTR`

### 语法
```erb
TRYCCALLFORM 目标(...)
    ; try 成功时执行这里
CATCH
    ; try 失败时执行这里
ENDCATCH
```

### 执行语义
- `TRYC*` 语句本身建立一个块；
- 成功时：正常落入 try 块体；
- 到达 `CATCH` 行时，`CATCH_Instruction` 会直接跳到 `ENDCATCH`，因此**catch 体被跳过**；
- 失败时：执行器把流程定位到 `CATCH` 行，下一轮从 **`CATCH` 后的第一行** 开始执行，也就是进入 catch 体。

### 真实示例
```erb
TRYCJUMPFORM KOJO%RESULTS%_COM_ABLE_K{NO:TARGET}_{ARG:3}
CATCH
    RETURN 0
ENDCATCH
```

示例出处：`ERB/口上・メッセージ関連/KOJO_MESSAGE.ERB:1059-1064`

```erb
TRYCCALLFORM SPIRIT_特殊私处_{NO:VIS_C}(服装)
    SIF RESULT
        私处 '= RESULTS
CATCH
ENDCATCH
```

示例出处：`ERB/魔改内容/GRAPH系.ERB:51-55`

### 源码
- 结构配对：`ErbLoader.cs`
- 调用执行：`FunctionIdentifier.cs`
- `CATCH` 行为：`FunctionIdentifier.cs`（`CATCH_Instruction`）

## 12. `TRY*LIST` / `FUNC` / `ENDFUNC`

### 语法

```erb
TRYCALLLIST
    FUNC 目标1(...)
    FUNC 目标2(...)

```

还支持：
- `TRYJUMPLIST`
- `TRYGOTOLIST`

### 执行语义
- 加载阶段把 `FUNC` 子项收集到 `callList`；


## 15. 数据块：`PRINTDATA` / `DATA` / `STRDATA`

## 15.1 `PRINTDATA` / `PRINTDATAL` / `PRINTDATAW`（及 K/D 变体）

### 语法
```erb
PRINTDATA [可选整型变量]
    DATA ...
    DATAFORM ...
ENDDATA
```

### 执行语义
- `PRINTDATA` 本身不接普通文本参数，而是持有一个 `dataList`；
- 运行时从所有数据分支中**随机抽一个列表**；
- 若给了可选整型变量，会把被选中的分支索引写进去；
- 然后逐条输出该分支下的 `DATA` / `DATAFORM`。

`PRINTDATAL`、`PRINTDATAW` 只是普通 `PRINT*` 的换行/等待输入变体；`K`/`D` 变体继承同名 `PRINT` 家族的编码/样式标记。

### 真实示例
```erb
PRINTDATA
    DATAFORM 抓紧%CALLNAME:TARGET%的屁股
    DATAFORM 搂住%CALLNAME:TARGET%的腰把屁股
    DATAFORM 像拉着韁绳一般抓住%CALLNAME:TARGET%的手腕让屁股
ENDDATA
```

示例出处：`ERB/口上・メッセージ関連/EVENT_MESSAGE_挿入系COM/EVENT_MESSAGE_挿入系派生コマンド.ERB:219-223`

## 15.2 `DATALIST` / `ENDLIST`

### 语法
```erb
PRINTDATAL
    DATALIST
        DATAFORM ...
        DATAFORM ...
    ENDLIST
    DATALIST
        DATAFORM ...
    ENDLIST
ENDDATA
```

### 执行语义
- `DATALIST` 把若干 `DATA*` 项打包成一个“候选列表”；
- `PRINTDATA` 从多个 `DATALIST` 之间随机挑一组；
- 组内各 `DATA*` 会按顺序全部输出。

### 真实示例
示例出处：`ERB/CASINO/駒草の賭場.ERB:1195-1206`

## 15.3 `DATA` / `DATAFORM`

### 语法
- `DATA`：普通字符串参数
- `DATAFORM`：FORM 字符串参数

二者都只能出现在 `PRINTDATA...ENDDATA`、`DATALIST...ENDLIST` 或 `STRDATA...ENDDATA` 块内。

### 真实示例
```erb
DATAFORM 店内的广播响了起来
DATAFORM 妖精女仆
```

示例出处：`ERB/CASINO/CASINO.ERB:221-227`

## 15.4 `STRDATA`

### 语法
```erb
STRDATA 目标字符串变量
    DATAFORM ...
    DATAFORM ...
ENDDATA
```

### 执行语义
- 与 `PRINTDATA` 类似，也是从内部 `dataList` 随机挑一组；
- 但不是输出，而是把所选组的各条文本以换行连接后写入目标字符串变量；
- 执行完成后直接跳到 `ENDDATA` 之后。

### 真实示例
```erb

    DATAFORM 「哦呀哦呀、难道是不留隔夜钱主义者吗？」/「那么我就满怀感激地接受吧♪」
    DATAFORM 「真是不敢相信、光是坐在这驹就在增加」/「这真是个…好赌场♪」
ENDDATA
```

示例出处：`ERB/CASINO/CASINO.ERB:219-228`

### 源码
- 配对：`ErbLoader.cs`
- 输出执行：`FunctionIdentifier.cs`（`PRINT_DATA_Instruction`）
- 写变量执行：`Process.cs`（`FunctionCode.STRDATA` 分支）
- 参数：`PrintDataArgument.cs`、`StrDataArgument.cs`

## 16.2 `THROW`

### 语法
```erb
THROW FORM字符串
```

### 执行语义
1. 先求出错误消息字符串；
2. 若当前已经在 `BEFORE_THROW` / `BEFORE_ERROR` 事件里，则直接打印并终止该路径；
3. 否则尝试触发 `BEFORE_THROW` 事件；
4. 若没有 `BEFORE_THROW`，直接抛出 `CodeEE`；
5. 后续 `Process` 的异常处理逻辑可能再进入 `BEFORE_ERROR`。

### 真实示例
```erb
CASEELSE
    THROW 未设置正确的获取内容。
ENDSELECT
```

示例出处：`ERB/魔改内容/qol/qol_weather.ERB:580-585`

### 源码
