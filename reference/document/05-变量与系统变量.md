## 1. 变量系统总览

### 1.1 底层类型与维度

Emuera / erabasic 的内置变量由 `VariableCode` 的 flag 组合描述；`VariableDescriptor.FromCode()` 会把这些 flag 还原成“类型 + 维度 + 属性”。

- **整数型**：底层是 `long`（64 位有符号整数）
- **字符串型**：底层是 `string`
- **浮点型**：内置系统变量里明确可见的只有 `RESULTF`；局部/引用/自定义变量还可通过 `LOCALF` / `ARGF` / `REFF` / `DIMF` 系列得到浮点数组
- **维度**：标量 / 1 维 / 2 维 / 3 维
- **作用域**：全局变量 / 角色变量 / 局部变量 / 用户定义变量 / 引用变量
- **存档行为**：由 flag 与 `VariableToken` 构造逻辑共同决定；`__GLOBAL__`、`__SAVE_EXTENDED__` 明确表示“需要保存”

### 1.2 访问语法（源码已确认）

`VariableParser.ReduceVariable()` 与 `ExpressionParser.ReduceVariableIdentifier()` 确认了以下语法：

1. **普通 1 维变量**：`VAR:索引`
2. **2 维变量**：`VAR:索引1:索引2`
3. **3 维变量**：`VAR:索引1:索引2:索引3`
4. **角色标量变量**：`NAME:角色ID`、`NO:角色ID`
5. **角色 1 维变量**：`TALENT:角色ID:项目ID`
6. **角色 2 维变量**：`CDFLAG:角色ID:项目1:项目2`
7. **局部变量跨函数访问**：`LOCAL@函数名:索引`
8. **字符串索引**：对支持关键字字典的变量，可把某些下标写成字符串，例如 `TALENT:MASTER:禁断的知識`、`CFLAG:TARGET:性格傾向`

源码还确认：

- **角色变量允许省略“角色ID”**（前提是未启用 `SystemNoTarget`）
  - 标量：`NAME` 等价于 `NAME:TARGET`
  - 1 维：`TALENT:恋慕` 等价于 `TALENT:TARGET:恋慕`
- **2 维角色变量 `CDFLAG` 不能省略参数**
- `变量名(...)` 在解析器里会优先按“函数调用”处理；本文**不确认** `TALENT(项目ID)` 这种写法可直接当作变量访问使用

### 1.3 访问示例（来自本仓库 ERB）

```erb
; 显式角色ID + 字符串项目名
IF TALENT:MASTER:禁断的知識

; 省略角色ID，默认 TARGET
IF !TALENT:恋慕

; 角色字符串数组
SIF CSTR:(ARG:1):0 == ""
    CSTR:(ARG:1):0 = /

; 局部变量外部访问（源码注释示例）
; LOCAL@DATE_EVENT:2 = 1
```

### 1.4 `VariableCode.cs` flag 含义

| flag | 含义 | 说明 |
|---|---|---|
| `__INTEGER__` | 整数型 | 底层 `long` |
| `__STRING__` | 字符串型 | 底层 `string` |
| `__ARRAY_1D__` | 1 维数组 | `VAR:idx` |
| `__ARRAY_2D__` | 2 维数组 | `VAR:i:j` |
| `__ARRAY_3D__` | 3 维数组 | `VAR:i:j:k` |
| `__CHARACTER_DATA__` | 角色变量 | 第 1 参数总是角色索引 |
| `__LOCAL__` | 局部变量族 | `LOCAL` / `ARG` / `LOCALS` / `ARGS` / `LOCALF` / `ARGF` |
| `__GLOBAL__` | 全局共享且存档 | `GLOBAL` / `GLOBALS` |
| `__EXTENDED__` | 扩展变量 | 非最早期标准变量；默认通常不保存 |
| `__SAVE_EXTENDED__` | 扩展但仍保存 | 常见于扩展角色变量、`TSTR`、`RANDDATA` |
| `__UNCHANGEABLE__` | 只读 | 常量 / 只读系统变量 |
| `__CONSTANT__` | 常量族 | 多与 `__UNCHANGEABLE__` 组合使用 |
| `__CALC__` | 计算型/伪变量 | 读时动态计算，如 `RAND`、`CHARANUM`、`LASTLOAD_*` |
| `__CAN_FORBID__` | 可禁用 | 当 `VariableSize.csv` 把长度设为 0 时，该变量可被“封禁” |
| `__UPPERCASE__` | 取高位 flag 的掩码 | 内部使用 |
| `__LOWERCASE__` | 取低位编号的掩码 | 内部使用 |

### 1.5 `VariableSize.csv` 与 `GameBase.csv`

- `CSV/VariableSize.csv` 可重定义绝大多数数组变量的长度；文件头注释明确说明：**CSV 常量数组、`RAND`、`CHARANUM`、非数组变量不能改长度**
- 本仓库示例：
  - `FLAG,10000`
  - `TALENT,1000`
  - `LOCAL,200`
  - `DITEMTYPE,100,100`
- `CSV/GameBase.csv` 提供 `GAMEBASE_*` 元信息，当前仓库前几行格式为：

> 注意：源码 `GameBase.cs` 识别的正式键名是 `作者`、`バージョン名`、`バージョン情報URL` 等；本仓库 CSV 的“弄ってみた人”并不是源码标准键名，兼容性需进一步验证。

### 2b.2 局部变量机制与 `@函数名` 作用域

`VariableLocal` 说明了 `LOCAL` / `ARG` 系列不是单一数组，而是“**按函数名分桶**”的局部 token 集合。当前函数直接写 `LOCAL:0` 即可；若要**跨函数/跨栈**访问某个函数自己的局部数组，语法是：

```erb
; 源码注释中的示例
; LOCAL@DATE_EVENT:2 = 1
```

- `@DATE_EVENT` 就是 `subKey`
- 只有 `LOCAL/LOCALS/LOCALF/ARG/ARGS/ARGF` 支持 `@子作用域`
- 若对全局变量写 `FLAG@XXX`，`VariableIdentifier.GetVariableId()` 会直接报错

### 2b.3 引用变量与内部“宏类别”变量

下列名字**出现在 `VariableCode.cs` 中**，但它们主要是**用户定义变量系统的内部类别码**：

| 变量名 | 类型 | 作用域 | 是否存档 | 对应 CSV | 简要说明 |
|---|---|---|---|---|---|
| `REF` / `REFS` / `REFF` | INT / STR / FLOAT 标量或 1D 引用族 | 引用 | 否 | 无 | `#DIM REF`、`#DIMS REF`、`#REF` 等声明出来的引用变量使用的内部类型码 |
| `REF2D` / `REFS2D` / `REFF2D` | 2D 引用 | 引用 | 否 | 无 | 2 维数组引用内部类型码 |
| `REF3D` / `REFS3D` / `REFF3D` | 3D 引用 | 引用 | 否 | 无 | 3 维数组引用内部类型码 |
| `VAR` / `VARS` | INT / STR 用户变量基类码 | 用户定义 | 否 | ERD / `#DIM` | 普通用户定义变量的内部类型码 |
| `VAR2D` / `VARS2D` | 2D 用户变量基类码 | 用户定义 | 否 | ERD / `#DIM` | 2 维用户变量内部类型码 |
| `VAR3D` / `VARS3D` | 3D 用户变量基类码 | 用户定义 | 否 | ERD / `#DIM` | 3 维用户变量内部类型码 |
| `CVAR` / `CVARS` | 角色用户变量基类码 | 角色用户定义 | 否 | `TCVAR.csv` / ERD / `#DIM CHARADATA` | 每角色一份的用户定义变量内部类型码 |
| `CVAR2D` / `CVARS2D` | 2D 角色用户变量基类码 | 角色用户定义 | 否 | ERD | 2 维角色用户变量内部类型码 |

> 关键点：
> - 这些名字不是 `varTokenDic` 里预置好的普通系统变量实例
> - 它们是 `UserDefinedVariableToken` / `UserDefinedCharaVariableToken` / `ReferenceToken` 体系在内部使用的“变量种类标签”
> - 在脚本层面，你通常看到的是 `#DIM DYNAMIC XXX`、`#DIM REF XXX`、`#DIMS REF XXX,0` 这种声明，而不是直接写 `VAR:...`

### 2b.4 本仓库中的引用变量真实用例

```erb
@DT_SELECT_SORTED_ID(ARGS_TABLE, ARGS_COL, ARG_DESC, REF_ARR)
#DIM REF REF_ARR
RETURN DT_SELECT(ARGS_TABLE, "", L_SORT_ORDER, REF_ARR)

@SPIRIT_GET_服差分(Version, VIS_C, 妊肚, 乳量, 服装)
#DIMS REF 妊肚,0
IF 服装 != "" && 妊肚 == "妊肚"
```

说明：

- `#DIM REF REF_ARR`：整数引用变量，常用于“把数组作为输出参数传进函数”
- `#DIMS REF 妊肚,0`：字符串引用变量；从用例看，这是**标量字符串引用**

## 3. 角色变量（按角色索引存取）

### 3.1 访问规则

源码 `VariableParser.ReduceVariable()` 明确区分三类角色变量：

1. **角色标量**（`NAME` / `NO` / `ISASSI` 等）
   - 完整：`NAME:角色ID`
   - 省略：`NAME` ≈ `NAME:TARGET`（仅在未启用 `SystemNoTarget` 时）
2. **角色 1 维数组**（`TALENT` / `CFLAG` / `BASE` 等）
   - 完整：`TALENT:角色ID:项目ID`
   - 省略角色：`TALENT:项目ID` ≈ `TALENT:TARGET:项目ID`
3. **角色 2 维数组**（`CDFLAG`）
   - 完整：`CDFLAG:角色ID:项目1:项目2`
   - 不能省略参数

### 3.2 字符串项目名

`ConstantData.GetKeywordDictionary()` 明确支持以下 CSV/字典型字符串下标：

- `ABL` → `Abl.csv`
- `EXP` → `exp.csv`
- `TALENT` → `Talent.csv`
- `PALAM` / `JUEL` / `GOTJUEL` / `CUP` / `CDOWN` → `Palam.csv`
- `MARK` → `Mark.csv`
- `BASE` / `MAXBASE` / `DOWNBASE` → `Base.csv`
- `SOURCE` → `source.csv`
- `EX` / `NOWEX` → `ex.csv`
- `CFLAG` → `CFLAG.csv`
- `TCVAR` → `TCVAR.csv`
- `CSTR` → `CSTR.csv`
- `STAIN` → `Stain.csv`
- `RELATION` → 角色字典（来自 `chara*.csv`）
- `CDFLAG` → 第二维用 `CDFLAGNAME1`，第三维用 `CDFLAGNAME2`

## 8. 变量 flag 位含义速查表（文末速查）

| 名称 | 位值 | 含义 |
|---|---:|---|
| `__NULL__` | `0x0` | 空/无 flag |
| `__CAN_FORBID__` | `0x10000` | 允许被 `VariableSize.csv` 设为 0 长度 |
| `__INTEGER__` | `0x20000` | 整数变量 |
| `__STRING__` | `0x40000` | 字符串变量 |
| `__ARRAY_1D__` | `0x80000` | 1 维数组 |
| `__CHARACTER_DATA__` | `0x100000` | 角色变量 |
| `__UNCHANGEABLE__` | `0x400000` | 只读，不可赋值 |
| `__CALC__` | `0x800000` | 计算型/伪变量 |
| `__EXTENDED__` | `0x1000000` | 扩展变量 |
| `__LOCAL__` | `0x2000000` | 局部变量族 |
| `__GLOBAL__` | `0x4000000` | 全局共享变量族 |
| `__ARRAY_2D__` | `0x8000000` | 2 维数组 |
| `__SAVE_EXTENDED__` | `0x10000000` | 扩展变量且会进入存档 |
| `__ARRAY_3D__` | `0x20000000` | 3 维数组 |
| `__CONSTANT__` | `0x40000000` | 常量族 |
| `__UPPERCASE__` | `0x7FFF0000` | 取高位属性位的掩码 |
| `__LOWERCASE__` | `0xFFFF` | 取低位变量编号的掩码 |

### 8.1 从 flag 组合读变量类别的例子

- `TALENT = 0x1B0003`
  - `__INTEGER__ + __ARRAY_1D__ + __CHARACTER_DATA__ + __CAN_FORBID__`
  - 含义：**整数 / 1 维 / 角色变量 / 可禁用**
- `CSTR = 0x111D0000`
  - `__STRING__ + __ARRAY_1D__ + __CHARACTER_DATA__ + __EXTENDED__ + __SAVE_EXTENDED__`
  - 含义：**字符串 / 1 维 / 角色变量 / 扩展变量 / 仍会存档**
- `ITEMPRICE = 0x14B003C`
  - `__INTEGER__ + __ARRAY_1D__ + __UNCHANGEABLE__ + __EXTENDED__ + __SAVE_EXTENDED__`
  - 其中“只读”是关键特征；源码实际用 `Int1DConstantToken` 创建，不可写；是否真正写入存档仍以 token 逻辑为准

> 最后一条需要注意：`VariableCode` 的位组合能表达“类别”，但**最终行为仍要以具体 token 类实现为准**。例如 `RAND`、`CHARANUM`、`LASTLOAD_*` 的“只读/计算”行为并不是单靠位值，而是由 `PseudoVariableToken` 子类实现的。
