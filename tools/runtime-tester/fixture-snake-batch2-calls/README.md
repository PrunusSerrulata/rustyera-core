Prepared only; no execution evidence is claimed here. `common/` contains syntax
supported by both pinned engines: exact CALLFORM and whole-array REF. The
non-character REF source index is not evaluated. Run the METHODS observation
group against the selected fixture root.

The root retains base.erb, tiny GAMEBASE.CSV, configuration and font identity from
the accepted 2A fixture. No executable, downloaded font, game or evidence is copied.

formal prefix. `pending/pending-common-extra/` isolates the excess-argument probe.

so ordinary fixture loading does not execute the pending fault probe. Actual
load/runtime phase, structured diagnostics, side effects and terminal result must
be captured and adjudicated before promoting an expectation.

arithmetic/RNG/layout/save/service identity checks. It does not normalize a C#
load-success/run-error result into Rust compileError. A genuine C# load rejection
stops before run and retains the raw response; stopped capture is not parity.
No reference source or pre-existing fixed fixture is modified.
